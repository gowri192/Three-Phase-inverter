# Three-Phase Inverter Simulation

## Overview

This project demonstrates the simulation and visualization of a **three-phase inverter** using **MATLAB and Simulink**.

The MATLAB script runs the Simulink model, extracts the inverter switching patterns and rotor/reference-vector position from the simulation data, and creates a dynamic visualization of the inverter switching states.

## Tools & Technologies

* MATLAB
* Simulink
* MATLAB Plotting
* Simulation Data Logging

## Features

* Three-phase inverter simulation using Simulink
* Analysis of inverter switching patterns
* Visualization of three-phase switching states
* Representation of three-phase axes at 120° separation
* Tracking of the rotating reference vector
* Dynamic animation of switching-vector transitions
* Processing of simulation data using MATLAB



The simulation data stored in `logsout` is then used to obtain:

* Inverter switching patterns
* Reference-vector angular position

The script defines three phase axes:

* **Phase A:** 0°
* **Phase B:** +120°
* **Phase C:** −120°

The six active switching states of the inverter are identified and represented graphically.

## Switching States

The script visualizes the following six active switching states:

| Switching State |
| --------------- |
| 100001          |
| 001001          |
| 011000          |
| 010010          |
| 000110          |
| 100100          |

These switching states correspond to the active voltage vectors generated by the three-phase inverter.

## Visualization

The MATLAB script creates a graphical representation containing:

* Three-phase axes
* Phase labels A, B and C
* Inverter switching-state indicators
* Rotating reference vector
* Positive and negative vector positions

The animation updates the vector position and switching state according to the simulation data.

## Running the Project

### Prerequisites

Install:

* MATLAB
* Simulink

The required Simulink model should be named:

```text
Modeling_three_phase_inverter.slx
```

### Steps

1. Download or clone this repository.
2. Place `text.m` and `Modeling_three_phase_inverter.slx` in the same MATLAB working directory.
3. Open MATLAB.
4. Run `text.m`.
5. The Simulink model will open and run automatically.
6. The MATLAB script will process the simulation data.
7. The switching states and rotating reference vector will be displayed as an animation.
